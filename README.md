# Zombie Shooter Map Editor

Zombie Shooter Map Editor is a Win32/x86 reconstruction of the original ZS1 map editor, prepared for Visual Studio 2022 while preserving the established editor behavior, file formats, rendering paths, scripting, map logic and legacy runtime compatibility.

Tested on Zombie Shooter 1 and Alien Shooter World. May support games that support the “World” layout.

## Build target

- Visual Studio 2022
- Platform toolset: v143
- Platform: Win32 / x86
- Recommended configuration: Release
- Runtime library: static CRT (`/MT` in Release)
- C++ language mode: C++17

Open `vs2022/MapEdit.sln`, select `Release | Win32`, and build the `MapEdit` project.

Historical Ogg/Vorbis Win32 static libraries are stored under `third_party/xiph/lib/Win32/Release`; the build does not download external packages.

The post-link step normalizes PE OS/subsystem compatibility metadata for the legacy Win32 runtime environment.

## Runtime data

The executable expects the normal Zombie Shooter editor/game data in its working directory. In particular, the runtime reads the editor/project `.cfg`, `Strings.ini`, game resources and, for terrain import, `mapedit.ini`.

Those game/runtime data files are not generated by the build. Use the files from a compatible Zombie Shooter installation/editor setup.

## Source layout

- `src/app` — application startup
- `src/editor` — editor UI and editing operations
- `src/engine` — maps, rendering, audio, resources, scripting and runtime logic
- `src/ui` — dialog helpers
- `src/zs1` — ZS1-specific scripting/user/help/high-score support
- `include/mapedit` — project headers grouped by subsystem
- `resources` — Windows resource image used by the editor build
- `third_party/xiph` — local Ogg/Vorbis static libraries
- `tools` — PE compatibility post-link helper
- `vs2022` — Visual Studio 2022 solution and project
